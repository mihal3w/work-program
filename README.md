Workday Checker Project
This project determines whether a given date is a workday or a day off based on a predefined work cycle.

Functionality
The program:

Takes user input for year, month, and day to check

Determines if the entered date is a workday or day off according to these rules:

The work cycle starts on July 17, 2024

The cycle consists of 2 workdays followed by 2 days off

This pattern repeats continuously

How to Use
Clone the repository

Run the script with python workday_checker.py

Enter the year, month, and day when prompted

The program will tell you whether the entered date is a workday or day off
